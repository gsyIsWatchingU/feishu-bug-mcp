# 项目界面中文汉化计划

## 1. 概述
将飞书 Bug 管理 MCP 工具中所有面向用户的英文文本翻译为中文，包括工具描述、参数说明、错误信息等。

## 2. 项目分析结论

### 2.1 当前项目特点
- 项目是一个飞书 Bug 管理的 MCP 服务器
- 工具定义文件主要位于 `src/tools/` 目录
- 部分工具已使用中文描述（如 `check_duplicate_bugs`），大部分仍为英文

### 2.2 需修改的文件列表
1. `src/tools/list-bugs.ts` - 列出 Bug 工具
2. `src/tools/analyze-bug.ts` - 分析 Bug 工具
3. `src/tools/fix-bugs.ts` - 修复 Bug 工具
4. `src/tools/update-bug-status.ts` - 更新 Bug 状态工具
5. `src/tools/helpers.ts` - 辅助函数中的英文文本
6. `src/tools/analysis-workflow.ts` - 工作流分析中的英文错误信息

### 3.1 src/tools/list-bugs.ts

- 参数描述翻译

- 参数描述翻译

## 4. 翻译原则
- 保持技术术语的一致性
- 保持项目原有功能不变
- 翻译后的文本应符合中文用户的表达习惯
- 代码注释和内部变量名保持英文不变

## 5. 验证方式
- 代码编译通过（运行 `npm run build`）
- 类型检查通过（运行 `npm run check`）
- 工具可以正常注册和调用

## 6. 风险处理
- 确保修改只涉及文本内容，不改变代码逻辑
- 对于不确定的翻译，保持与项目中已有的中文表达一致
